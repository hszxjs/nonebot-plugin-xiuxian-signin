## 2. 修为需求

公式（`domain/roots.py:250` `realm_progress_required`）：

```
需求(境 i) = 根基数 × 2^i        （i = realm_index，0 起）
累计(境 i) = 根基数 × (2^(i+1) − 1)
```

根基数由灵根决定（`domain/models.py:272` `Root.progress_required`）：

```
根基数 = max(55, tier_base + grade_extra + int((80 − 纯度) × 0.55))

tier_base:  变异灵根 82 | 天阶 100 | 地阶 115 | 玄阶 135 | 黄阶 155 | 凡品 180
grade_extra: 极品 0 | 上品 8 | 中品 18 | 下品 28
```

## 4. 现状结论：指数墙

`2^i` 曲线在 i≈20 之后彻底压过任何线性来源：

- 境 20 需求 1–2.3 亿，境 34 需求 **1.6–3.8 万亿**；
- 而每日签到只有 **5–51** 点。

也就是说，**纯签到在境 15 以后已经不可能推进**，高境实际依赖副本、双修、功法的额外产出。
这不是 bug，但意味着「每境预期天数」这个指标只在前期有意义：境 0–5 用签到约
**1–2 周/境**（凡品下品）到 **3–6 天/境**（天阶极品），之后必须换算法。

**待办（R-39）**：新秘境经济定稿时，需要给出「每周基础入场次数 + 活跃度解锁 + 天机阁身份加成」的
产出侧口径，并与本文的 §2.2 需求侧对齐——否则新玩法上线后仍然只影响前期。
